## 1. LangChain 架构

（Core / Community / Experimental 分层，版本管理）

## 2. LCEL 管道符

（`|` 的本质：RunnableSequence，统一 invoke/stream/ainvoke/astream 接口）

## 3. Prompt 体系

| 组件 | 用途 |
|------|------|
| PromptTemplate | 字符串模板 |
| ChatPromptTemplate | 聊天消息模板 |
| MessagesPlaceholder | 动态消息槽 |
| Few-shot | 示例引导 |

## 4. OutputParser 体系

| 解析器 | 用途 |
|--------|------|
| StrOutputParser | 直接取文本 |
| JsonOutputParser | 解析JSON |
| PydanticOutputParser | Schema验证 |
| with_structured_output | 原生结构化输出 |

## 5. Chain 模式

- RunnableLambda：自定义转换逻辑
- RunnablePassthrough：透传输入

## 6. Stream 与异步

| 方法 | 类型 | 场景 |
|------|------|------|
| stream() | 同步流式 | 基础使用 |
| astream() | 异步流式 | 并发场景 |
| astream_events() | 事件流 | 调试/监控 |

## 数据流图

```
用户输入
```
